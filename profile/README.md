<p>这篇按路由器端来写：先判断手上的设备能不能承担代理转发，再对比直填、旁路由、终端配置三种接法，然后给旁路由的配置顺序和策略路由的分组方法，最后讲无线差异与验证回滚。</p>
<h2>一、先判断设备能不能扛</h2>
<p>家用路由器要跑代理，得看处理器和内存，百元级设备开转发后跑不满百兆很常见。</p>
<p>固件也要支持，原厂固件大多只能设静态路由，装不了代理插件，需要刷第三方固件或加旁路由。</p>
<p>不确定就先测，开转发后跑一次测速，掉速超过一半就别硬撑。</p>
<h2>二、三种接法怎么选</h2>
<p>第一种是路由器直接填上游代理，配置最简，但只能整网走一条线路，无法按设备分。</p>
<p>第二种是加一台旁路由，主路由只做拨号和无线，代理逻辑放在旁路由上，灵活度高。</p>
<p>第三种是每台电脑单独配客户端，不碰路由器，适合设备少、要求精细的场景。</p>

<h2>三、旁路由的配置顺序</h2>
<p>先把旁路由接在主路由的 LAN 口上，给它设一个同网段但不冲突的固定地址。</p>
<p>关掉旁路由的 DHCP，网关指向主路由，DNS 先填公共地址，确认能上网。</p>
<p>再装代理服务，填上游地址和认证信息，本地监听开在旁路由地址上。</p>
<h3>网关怎么指</h3>
<p>需要走代理的设备，把网关改成旁路由地址；不需要的保持主路由，这是最省事的分流方式。</p>
<h3>主路由要不要动</h3>
<p>能不动就不动，主路由改动影响全屋，旁路由坏了拔掉就能恢复，风险小得多。</p>
<h2>四、策略路由怎么分组</h2>
<p>按设备分组，运营组走美国线路，客服组走另一条，行政设备直连。</p>
<p>按目标域名分流更细，但规则多、维护成本高，先按设备分，够用就别加复杂度。</p>
<p>规则写好后固定下来，别频繁改，改动要记录时间和原因。</p>
<h2>五、无线与有线的差异</h2>
<p>无线转发会多一层抖动，代理本身又有延迟，两者叠加后后台操作容易卡。</p>
<p>关键岗位尽量走有线，无线留给手机和临时设备。</p>
<p>双频路由器把代理设备放在五 G 频段，干扰少一些。</p>
<p>家里如果有摄像头、电视这类常在线设备，让它们留在主路由直连，别跟代理线路抢并发和带宽。</p>
<h2>六、验证与回滚</h2>
<p>验证分三步：设备网关是否指向旁路由、出口地址是否为预期、断网后能否自动恢复。</p>
<p>上线前把原配置导出备份，出问题十分钟内能切回原状态，这比调优更重要。</p>
<p>第一次改完先观察一天，别在旺季或大促当天动网络。</p>
<h3>改动的时间窗</h3>
<p>选在业务低峰动手，动之前通知到使用的人，避免有人正在改价或回消息。</p>

<h2>常见问答</h2>
<h3>普通家用路由器能直接装代理插件吗？</h3>
<p>答：多数原厂固件不行，只支持静态路由和端口转发。能装插件的一般是可以刷第三方固件的型号，刷之前确认硬件版本和恢复方式，避免变砖。</p>
<h3>用路由器走代理，所有设备都会走同一条线路吗？</h3>
<p>答：路由器直填代理时是这样。要按设备区分，得用旁路由加策略路由，或者让不同设备指向不同网关。</p>
<h3>旁路由会不会拖慢整个网络？</h3>
<p>答：只影响指向它的设备。流量经过旁路由转发会多一跳，延迟增加几毫秒到几十毫秒，主要看旁路由性能和上游线路质量。</p>
<h3>手机连Wi-Fi也能自动走代理吗？</h3>
<p>答：可以。手机网关指向旁路由后流量会被接管，不需要在手机上单独设置。但要确认旁路由的无线覆盖，信号弱会明显影响体验。</p>
